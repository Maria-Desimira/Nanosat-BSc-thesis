# Nanosat-BSc-thesis
This Repository contains source codes for Nanosat and Ground Station 

Този проект се състои от две части:
1. Код за наземна станция:
намира се във файла GroundStation и работи на платформата Arduino IDE.
Да се използва първа версия на Библиотеката за Grove LoRa 
3. Код за наноспътник:
Намира се в директорията Nanosat и работи на платформата Raspberry Pi.
Директорията съдържа следните файлове:
main.py - основния на програмата, който се стартира за успешна работа
gps.py; temp.py; imu.py - файлове, които се извикват в главната фунцкия - те съдържат функции за имерване на съответните данни
RH_RF95 и RHUartDriver - са файлове за съвместимост при комуникация с LoRa модула и съответната Arduino библиотека.
